VORA Ops — voir le service vivre, et trancher vite

Six écrans web en 1440 px pour une équipe de deux ou trois personnes. Le tableau de bord met le SOS avant tout le reste ; la file des dossiers se traite dans l'ordre d'arrivée avec un objectif de 48 h ; la fiche chauffeur permet de refuser une pièce avec un motif type et une consigne ; le litige montre les deux traces GPS et propose une décision pré-remplie ; les zones et les tarifs sont les deux leviers qui font vivre le géorepérage moto et le prix ferme. La connexion (OP-01) et les exports (OP-08) sont des écrans standards, non dessinés.

Même charte, densité de bureau : texte 13 px, boutons 36 px, tableaux. Sur un écran étroit, les cadres ci-dessous se réduisent automatiquement.
