Passagers

Trois gestes pour commander.

Pas d'adresse à connaître, pas de prix à négocier, pas de doute sur la voiture qui s'arrête.

1

Dites où vous allez, comme vous le dites

Un carrefour, un marché, « en face de ». VORA connaît les repères de Yaoundé, pas seulement les rues. Vous pouvez aussi placer l'aiguille vous-même et ajouter une photo du lieu.

2

Voyez le prix ferme, décomposé

Prise en charge, distance, temps. Le prix affiché avant de commander est le prix payé, en espèces ou par Mobile Money. La seule chose qui peut le changer, c'est vous, en ajoutant un arrêt.

3

Reconnaissez votre chauffeur, dites le code

Photo, prénom, plaque, badge Vérifié. Vous dites votre code de montée à 4 chiffres, la course démarre. Sans le bon code, aucune course ne peut commencer.

Où

Yaoundé d'abord.

Les voitures VORA circulent partout. Les motos VORA servent la périphérie, là où les taxis ne vont pas, et jamais dans le centre urbain que l'arrêté préfectoral leur interdit : l'appli refuse une course moto avant même de la proposer à un chauffeur.

Questions fréquentes

Ce qu'on nous demande.

Le prix peut-il changer pendant la course ?

Non. Le prix ferme affiché avant la commande est le prix payé. La seule exception : vous ajoutez un arrêt, et le nouveau prix est affiché et accepté avant d'être appliqué.

Qu'est-ce que le code de montée ?

Un code à 4 chiffres affiché dans votre appli. Vous le dites au chauffeur, la course démarre. Il garantit que vous montez dans le bon véhicule, et protège aussi le chauffeur.

Les motos VORA circulent-elles dans le centre-ville ?

Non. Le centre urbain de Yaoundé est interdit aux motos-taxis par arrêté préfectoral. L'appli refuse toute course moto dont le départ, l'arrivée ou l'itinéraire touche cette zone.

Combien VORA prend-il aux chauffeurs ?

15 % sur les courses en voiture, un forfait de 50 F par course en moto. Le net est affiché avant d'accepter, avec la retenue fiscale de 1 % que VORA reverse pour le chauffeur.

Mon numéro de téléphone est-il visible ?

Jamais. Chauffeur et passager se parlent par la messagerie et l'appel VORA, sans échanger de numéro. Chaque compte a un ID VORA pour le support et les reçus. Vous pouvez vous inscrire avec un téléphone ou un e-mail.

Que se passe-t-il si j'annule ?

Gratuit pendant 2 minutes après l'acceptation, ou tant que le chauffeur n'a pas parcouru 300 m. Ensuite, 300 F (100 F en moto) sont reversés au chauffeur pour son déplacement, et ajoutés à votre prochaine course.

Prêt pour le prochain trajet ?

L'appli VORA est gratuite sur Android. Espèces, MTN MoMo et Orange Money acceptés. Chauffeurs : le dossier se dépose depuis l'appli, en plusieurs fois si besoin.
